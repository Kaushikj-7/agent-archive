## Cost boundaries and interpretation

The scale query uses two normalized memberships; the separate route control
uses 32. Node and payload ceilings derive from actual tree height, page/lookahead,
count/boundary paths, bounded native identity batches and actual caller authority
observations, using the [documented equations](README.md). Each head allows16KiB,
each coordinator4MiB, each logical page/batch32MiB tree bytes, and nodes128KiB.
Actual returned bytes below are distinct from these conservative ceilings and
from provider HTTP/XML/TLS wire bytes. The modest tested phases do not establish
worst-case latency or a universal constant number of GETs: increasing tree height
can add bounded path reads. API-page authority counts are not whole-CLI counts.

Cold list/show First uses head 1/coordinator 1 and 8 tree GETs at 10k; at 100k it
uses 10 tree GETs. Cold handoff First adds the model return freshness observation,
using head 2/coordinator 1 and 8/9 tree GETs at 10k/100k. Cold list/show Older uses
head 1/coordinator 1 and 2/1 tree GETs; handoff Older uses head 2/coordinator 1 and 2.
Native first phases also own exact-identity lookup batches and model refill.
R=120 archived-only First uses 53 total GETs at both sizes; Older consumes its
cached buffer with head 2/coordinator 0/tree 0. These counts include deliberate
freshness work rather than concealing it as setup.

Baseline Older has no remote work because the baseline already loaded its
universe. Candidate Older includes new remote pages or fresh head validation.
At10k its measured Older latency is higher than baseline's eager-memory return;
at 100k baseline latency varies substantially. Preserve the raw spread rather
than interpreting two-repeat medians as a stable performance guarantee.

Native stats are attempted injected `Lstat` calls; activity refs are references
supplied to the real provider; opens are successful wrapped file opens and bytes
are actual descriptor reads. Internal `EvalSymlinks` syscalls are not individually
metered. Candidate First observesR registrations; Older reuses that observation.
Local labels attempt at most 50 per operation, including the next 50 onR=120
Older. Archive work and native work are separate; unlimitedR is not constant cost.
